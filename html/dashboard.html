HOW EQUIPMENT PRICES ARE SET

Crafting Fee + Max Material Cost + 30% Profit = base price. A range is added by rounding up to the nearest clean number.

Example — Rusted Greatsword: 2,200 (fee) + 1,300 (mats) + 1,050 (30% profit) = 4,550 → range 4,550 – 5,000 🪙
